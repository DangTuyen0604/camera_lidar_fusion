# Navigation maps

`warehouse_map.yaml` is the deterministic map used by the complete warehouse
demo. AMCL instead localizes against `warehouse_localization_map.yaml`
(published on `/localization_map`): the same world restricted to geometry that
crosses the LiDAR scan plane, at 0.025 m with its origin shifted by half a cell
to compensate nav2_amcl's cell-centre convention. Both are regenerated by
`tools/generate_warehouse_map.py`. When passing another `map:=`, pass the same
file as `localization_map:=` unless it has its own localization variant.
`warehouse_slam_map.yaml` is a map captured from the simulated robot with the
workflow below.

# Mapping and reload workflow

Start the warehouse and `mapping.launch.py`, teleoperate through every aisle,
then save the actual SLAM map with:

```bash
ros2 service call /map_saver/save_map nav2_msgs/srv/SaveMap \
  "{map_topic: map, map_url: warehouse_slam_map, image_format: pgm, map_mode: trinary}"
```

Pass the resulting YAML to localization or the full demo with
`map:=/absolute/path/warehouse_slam_map.yaml`. AMCL owns `map -> odom`; the MuJoCo
simulator owns only `odom -> base_footprint`, so the TF tree has no duplicate publisher.
