# Runtime evidence checklist

These files must be captured from a successful live run; generated or stock
images are not accepted:

| Evidence | Required file |
|---|---|
| Architecture and live graph | `docs/images/architecture.png` |
| Warehouse | `docs/images/warehouse.png` |
| Correct / incorrect projection | `docs/images/projection_correct.png`, `projection_incorrect.png` |
| Fused detection | `docs/images/fused_detection.png` |
| Costmap obstacle | `docs/images/costmap_obstacle.png` |
| Pallet replan | `docs/images/pallet_replan.png` |
| Person stop | `docs/images/person_stop.png` |
| Box avoidance | `docs/images/box_avoidance.png` |
| Docking | `docs/images/docking.png` |
| Benchmark plots | the seven PNG files under `benchmark_results/` |

Capture evidence in the later test session after Gate 6.1 and Gate 6.2 pass.
Do not commit an empty stand-in or a plot produced from synthetic sample data.
